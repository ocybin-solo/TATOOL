Closed Beta README file

**What is this app?** 
This app is like a sandbox for creating trippy animations.   There are several patterns to choose from, and several ways to add visual effects to the pattern that you choose.   The app uses what is known as a multiple pass shader system, and you can think of it like painting a picture in several clear layers, where each layer adds a brand-new detail on top of the last one.   There are references below if you would like to learn more about shaders.
**What is it used for?**
If you think that kaleidoscopes and mandalas and whatnot are beautiful, then you might enjoy just playing around in it for awhile.  This app lets you create a kaleidoscope with an underlying pattern. You can even add wavy effects on top of that, so that you have a swirling vortex like animation that has a spinning kaleidoscope *inside* of it.  
**How do you use it?**
There is a simple control scheme:

* ← &→ = modifies values inside a menu row
* ↑ & ↓ = scroll through menu lists
* 🟢= Confirms a menu selection
* 🔴= Cancels or returns from a menu
* 🔵= Opens the Lab (where we customize the animation)
* 🟡= Opens the Main Menu (options like background color, controller layout, exit app)
 
**CLOSED BETA TESTERS // GUIDE FOR LEARNING HOW TO USE**
 Please use this guide to familiarize yourself with the way the app works:
 1) Open the app
	 1) Are all eight buttons properly displayed and accessible on your device?
		 1) If not, please let me know at ocybin@gmail.com	
 2) Push the 🔵 button to open the Lab.  This should open the PASS MENU
	 1) Use the ↑ & ↓ buttons to navigate the list, then highlight : Pass 1: Base Pattern, then press the 🟢to confirm
 3) You should see a new menu called SELECT MATH RECIPE CARD..  Scroll down and highlight the option "Domain-Warp : Cyber Veins", then press 🟢to continue
 4) You should now see an animated pattern on the screen, and a new menu!
	 1) scroll down and select "NOISE DETAIL"
	 2) Now use the ← and → to change the value of the noise
	 3) Pick whatever value you like here, then press 🔴 to back out of the menu.  
	 4) Press the 🔵button two times to close and reopen the Lab.
 5) Select PASS 2 : WARPING.
	 1) This menu is unique insofar as we can select multiple effects.  In pass one, you can only select one pattern at a time, and in pass three, only one post processing filter can be applied.  However here in pass two, we can sequentially stack effects on top of one another.  Let me give you an example : 
		 1) Select Kaleidoscope - as soon as you hit the 🟢button to select it, it appears and begins to swirl.  This is a bug, but we can fix it right away by selecting rotation speed.  If you select sensitivity and use the ← and → keys, you can bump up the amount by which you modify the value row.  Go ahead and set the value to ZERO, then press 🔴two times to return to the math recipe menu.
		 2) Now Select Radial Swirl > Rotation Speed > and set it to around 0.75
		 3) OK - Take note of how the animation looks - Now we will undo our work, and see what happens when we apply radial swirl first, and then the kaliedoscope
		 4) Navigate back to the Math Recipe Card (in pass 2), then select RESET PASS TO BYPASS.  This clears out any active effects inside the 2nd pass.
		 5) Now, apply a radial swirl, then apply a kaleidoscope reflection
 6) Press 🔵twice to return to the first menu in the Lab.  Then, select PASS 3 : FILTERS
	 1) Select Analogue Edge Glow
 7) Return to the first menu again, then PASS 1, then global uniforms.  See what happens when you rotate the underlying pattern, underneath all the effects.

**Presets**
Once you have customized an animation and like it, go ahead and push the 🟡button to open the Main Menu.   Navigate to and select PRESETS, then select SAVE. 
* Are you able to use your mobile device's keyboard to type in a unique name for the preset? 
* If not, press 🟢to save it using a default name.
Press  🟡or 🔴to back out of the main menu and enter the lab with🔵, navigate to RESET ALL PARAMETERS and press 🟢-  This should completely reset the effects in both PASS 2 an PASS 3, so you can create another animation
